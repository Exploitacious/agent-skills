# grill-me

Adapted from the `grilling` skill in
[mattpocock/skills](https://github.com/mattpocock/skills) (MIT, copyright Matt
Pocock) at commit 85f83d3fde1d. Rewritten for this library: no emojis, the

and model invocation left enabled so it fires on its own at intake. Upstream
credit stays with the original author; see the repository LICENSE and the
